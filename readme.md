# SenceSpace – personal website

A personal web project connecting **design and front-end development**.  
A space for ideas, projects, and experimentation.

---

## About the project

**SenceSpace** is my personal website, developed as a long-term project.  
It serves as a place to present my work, test ideas, and explore the balance between aesthetics, functionality, and technical execution.

It is not just a portfolio, but an open space for development and experimentation.

---

## What you will find here in the future

- Design concepts and visual explorations
- Experiments with layout, typography, and animations
- Front-end built step by step, with a focus on **readability, rhythm, and detail**
- A connection between the digital world and print design

---

## Technologies used

- **HTML**, **CSS** – layouts, typography, responsiveness
- **JavaScript** – interactivity and front-end experiments
<!-- **Figma**, **Adobe Illustrator**, **Photoshop** -->

## Project status

The project is **in progress** and continuously evolving.

- Some parts serve as an experimental playground
- Others are moving towards the final version of the personal website
